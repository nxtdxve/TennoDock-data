# Focus node glyphs (sources)

Glyphs of the 75 current focus nodes (10 ways and 5 Tauron Strike nodes per school) for the focus tree in TennoDock (#121,
#126). Digital Extremes' Public Export names an image for every node but serves a blank white square. TennoDock uses only the
alpha channel, as a mask.

**Rights:** The images are © Digital Extremes (Warframe). Whether TennoDock may ship them in a published app is an open legal question for TennoDock's release phase (phase 9). They are used here for informative purposes only; TennoDock is not affiliated with Digital Extremes. The WARFRAME Wiki provides them as `Focus<Name>(xBlack).png`; wiki content is licensed CC BY-NC-SA 3.0.

**Fetched** on 2026-11-05 through the MediaWiki API (`iiurlwidth=128`), scaled to 80 × 80 px, coloured black and saved as
WebP (alpha lossless). File name: school folder in the game path and the last part of the path, e.g.
`/Lotus/Upgrades/Focus/Power/Residual/EnergyOverTimeFocusUpgrade` → `Power-EnergyOverTimeFocusUpgrade.webp`.
