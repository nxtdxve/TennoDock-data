# Damage types (sources)

Symbols of the 13 damage types, shown next to their name in TennoDock (#49, #103, #153): effect lines of mod cards, riven
stats (page and in-game overlay card "Riven check") and the element of Kuva and Tenet weapons. Digital Extremes' Public
Export has no plain damage-type symbols; it shows them only inside larger pictures (Nightwave badges, profile glyphs, arcane
pictures), which are unusable at 12 to 18 px.

was uploaded to the wiki on 2024-10-04 (all 13 on the same day). Saved as lossless WebP: every visible pixel is the same as in
the wiki file (checked 2026-11-06); libwebp may change the colour of fully transparent pixels. File name: the damage type as
TennoDock names it (`DAMAGE_TYPES` in `core/ui/damage-type-icon.tsx`).
