# Syndicate logos (sources)

Logos for the syndicate cards in TennoDock (#115, #126), only for the ten syndicates whose logo Digital Extremes does not
serve in its Public Export. TennoDock tints the shape itself (`colour` on `backgroundColour` from `ExportSyndicates`), so
each file is the one-colour version. File name = tag of the syndicate.

**Rights:** The images are © Digital Extremes (Warframe). Whether TennoDock may ship them in a published app is an open legal question for TennoDock's release phase (phase 9). They are used here for informative purposes only; TennoDock is not affiliated with Digital Extremes. The WARFRAME Wiki provides them; wiki content is licensed CC BY-NC-SA 3.0.

**Fetched** on 2026-11-05 through the MediaWiki API (`action=query&prop=imageinfo`), scaled to 256 × 256 px and saved as
WebP (quality 0.9). Chosen is the logo the game shows for the syndicate (wiki page "Syndicate"), not a rank sigil.
